# Warhammer 40k Simulator v. 0.0.1

Компьютерная симуляция настольной игры Warhammer 40,000 (10-я редакция) на Java.

Цель проекта — перенести основные механики игры (фазы, расчёт урона, контроль целей, Battle-shock и т.д.) в цифровой формат с возможностью дальнейшего добавления графического интерфейса (JavaFX).

## Текущий статус
- Частично реализована базовая модель юнитов (класс UnitProfile и наследники)
- Валидация характеристик по правилам 10-й редакции
- Сравнение юнитов по профилю (equals/hashCode)

## Требования
- Java 17+
- Maven (или Gradle)

## Планы
- Реализация оружия и способностей
- Симуляция фаз боя
- Графический интерфейс (JavaFX)
- Поддержка нескольких фракций
